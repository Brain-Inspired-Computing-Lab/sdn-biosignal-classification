# SDN Bio-Signal Classification

This repository provides preprocessing code for the EEG and ECG datasets used in the manuscript:

**"A Low-Power, Real-Time, and Noise-Resilient Spiking Neural Network for Bio-Signal Classification on a Neuromorphic Processor"**

The raw datasets are not included in this repository. Users should download them from the original public repositories:

* OpenNeuro ds004504 v1.0.9: https://openneuro.org/datasets/ds004504/versions/1.0.9
* PhysioNet PTB-XL v1.0.3: https://physionet.org/content/ptb-xl/1.0.3/

The preprocessing code is located in:

```text
dataset/preprocessing/
```

This repository does not redistribute raw or processed datasets. The preprocessing code can be used to regenerate the processed input data from the original public datasets.
